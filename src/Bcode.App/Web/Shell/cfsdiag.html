Xuất ĐẦY ĐỦ bộ chỉ tiêu khai báo của khách hàng
File Excel báo cáo chỉ có số liệu nên chỉ đoán được gần đúng. Để kiểm tra chính xác (TK nguồn, TK đối ứng, các cờ công nợ / không âm / đầu-cuối kỳ…), chạy các câu lệnh dưới trên database của khách (tab SQL của Bcode, chỉ select), xuất kết quả ra Excel (giữ nguyên tên cột) rồi chọn file đó ở ô “Khai báo chỉ tiêu …”. Một file có thể chứa nhiều mẫu (cột form) — chương trình tự lấy mẫu có nhiều dòng nhất.
Dán bộ chỉ tiêu khai báo
Chạy câu select * from v20gltc1 / v20gltc6 / v20gltc5 where form = '…' trên database của khách (nút “SQL lấy bộ chỉ tiêu” có sẵn câu lệnh), chọn cả bảng kết quả (kèm dòng tiêu đề cột) rồi Copy và dán vào đây. Nhận kết quả ngăn bằng Tab (copy từ lưới / Excel), dấu | (sqlcmd) hoặc dấu phẩy / chấm phẩy.
