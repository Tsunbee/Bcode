# Bản đồ cấu trúc Bcode & BcodeViewer (21/10/2026)

Đọc file này TRƯỚC khi tìm code. Tài liệu đầy đủ kèm sơ đồ: `Cấu trúc Bcode  BcodeViewer (v3).docx`. Đường dẫn bên dưới tính từ `src/<project>/`.

## Quan hệ

- Bộ Bcode gồm 5 chương trình (.exe) + 1 thư viện nhúng, cùng nằm trong solution Bcode.sln (D:\Bee\Tool\BcodeProject\Bcode-main), đều xoay quanh FastBusiness ERP và định dạng file điều khiển "FCode" (controller XML kiểu Dir/Grid/Filter/Report, SQL và JavaScript nhúng bên trong).
- Bcode.App (Bcode.exe) — bộ công cụ quản trị/triển khai ERP, bản dựng lại của FCode: SQL Query/Table, WCommand, File Lookup, Gen Update, Advance Note, API LT3, tạo báo cáo, check LCTT/CĐKT, biên bản Word... Gần như mọi màn hình là một trang HTML trong WebView2 (Web/Shell/*.html), C# chỉ giữ dữ liệu và nghiệp vụ. Có 2 chế độ giao diện chọn lúc mở (--web / --native): Web (WebView2) và App (WinForms tự vẽ — NativePage / NK.* / Native*Control thay trang HTML, cùng giao thức action nên nghiệp vụ dùng chung).
- BcodeViewer.App (BcodeViewer.exe) — trình soạn file controller FCode xây trên Monaco: IntelliSense nhiều lớp, F12/Peek entity, xem trước Dir/mail, chạy SQL, AI ghost text. Từ bản này cả menu/toolbar/cây file cũng vẽ trong trang (Web/shell.js) — WinForms chỉ còn là vỏ.
- Bcode.ScreenDesigner (BcodeScreenDesigner.exe) — thiết kế/xem trước màn hình Dir có dữ liệu mẫu; Bcode mở từ menu "Triển khai" hoặc chuột phải cây WCommand. Bcode.KeyGen — công cụ riêng của người phát hành, cấp key bản quyền gắn theo máy. Bcode.ReportBuilder — thư viện (DLL) "Tạo báo cáo" Bcode tham chiếu. BcodeNote.App (BcodeNote.exe) — Note (New) cho NHIỀU dự án: tham chiếu thẳng Bcode.dll (InternalsVisibleTo), dùng lại AdvanceNoteControl/advnote.html, GenAllService, WCommandService, QuickListForm; đọc-ghi cùng AdvanceNotes\<dự án>.json với Bcode.
- Chia sẻ giữa các chương trình: (1) %AppData%\Bcode\settings.json (workspace, kết nối CSDL) do Bcode ghi, BcodeViewer/ScreenDesigner đọc; BcodePaths.cs là bản sao giống hệt ở mỗi app để chọn đúng thư mục ghi được. (2) Code link bằng <Compile Include> chứ không chép: Shared/AiWebHelper.cs (Bcode + Viewer), Shared/LicenseCodec.cs (Bcode + KeyGen), Shared/DpapiText.cs (Bcode + Viewer: mật khẩu / API key trong settings.json mã hoá DPAPI), Shared/AppUpdate.cs + AppUpdateDialog.cs + AppUpdateForm.cs + AppUpdateToast.cs + Release.targets (Bcode + Viewer + ScreenDesigner: cơ chế cập nhật bản mới, mỗi app thư mục phát hành riêng; AppUpdateForm = hộp cho Viewer / Designer), Host/IncludeTree.cs (Viewer + ScreenDesigner), Monaco/theme.js/fcode-language.js của Viewer (Bcode dùng cho preview File Lookup).
- Liên lạc giữa tiến trình: Bcode → Viewer bằng Process.Start (file + tên project); Viewer → Bcode qua named pipe Bcode.Control.<session> bằng lệnh "sql|<b64 script>|<b64 tiêu đề>" ("Debug trong Bcode" mở tab SQL Query); BcodeNote → Bcode cùng pipe bằng "sqlp|<b64 script>|<b64 tiêu đề>|<b64 dự án>|<0 App/1 Sys>" (mở script gói vào tab SQL Query đúng App/Sys; khác dự án đang mở thì có dòng cảnh báo đầu script — MainForm.OpenProjectScriptTab); Bcode còn xử lý lệnh "fsg|<file>|<project>" nhưng Viewer hiện KHÔNG gửi (F5 của Viewer mở trình duyệt qua Host/MenuLauncher) — Services/ViewerControlServer.cs; Bcode → ScreenDesigner bằng Process.Start --source --project --controller; Viewer chạy 1 bản mỗi phiên Windows (Mutex + pipe BcodeViewer.SingleInstance.<session>).
