Chọn file Excel mẫu in và file .rpt template ở trên để bắt đầu.

Bấm vào một ô để chỉnh sửa.
Ctrl+bấm để chọn thêm, hoặc kéo chuột trên vùng trống để quét chọn.

Nguồn đối chiếu: file .xsd nếu có (chính xác nhất), không thì đọc từ template .rpt. Bấm tên trường để chèn vào section đang chọn. Trường màu đỏ là không có trong template — sẽ thành placeholder [...].
